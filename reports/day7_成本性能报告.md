## 五、解读要点

- TTFT 较高通常与模型先输出思维链(think)有关；关闭思维链可显著降低首 token 延迟。
- RAG 的 input token 占大头（检索分段），优化召回段数/精简 Prompt 可降本。
- 成本随调用量线性增长，上线前要按预期 DAU 估算月度账单。
- 并发加速受模型 API 限流(RPM/TPM)制约，超出会 429，需要限流与降级。
